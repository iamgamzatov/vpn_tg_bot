🛡️ Gamzi VPN Telegram Bot

Автоматизированный сервис по выдаче VPN-подписок на базе протокола VLESS Reality. Бот позволяет пользователям получать персональный доступ к VPN за считанные секунды через Telegram.
🚀 Основные возможности

    Автоматизация: Полная интеграция с панелью 3x-ui через API.

    Безопасность: Использование современного протокола VLESS Reality (высокая устойчивость к блокировкам).

    Триал-система: Автоматическая выдача временных ключей (триал на 3 дня) при вводе промокода.

    User-friendly: Удобная выдача конфигураций в буфер обмена и ссылки на скачивание клиентов для Android/iOS.

🛠 Технологический стек

    Язык: Python 3.x

    Библиотеки: aiogram (асинхронный фреймворк для Telegram ботов)

    VPN-инфраструктура: Xray-core

    Управление сервером: 3x-ui (панель управления)

    Протокол: VLESS + Reality (TLSR)

⚙️ Архитектура

    Пользователь вводит промокод в боте.

    Бот обращается к API панели 3x-ui для создания нового inbound-клиента.

    Панель генерирует уникальный ключ (UUID).

    Бот формирует VLESS-ссылку для импорта и отправляет пользователю вместе с инструкцией.
